# Catch Kanami Credits

This game is hand-written for Kanami.top.

Original reference and thanks:

- [ImKennyYip/whac-a-mole](https://github.com/ImKennyYip/whac-a-mole) by Kenny Yip, a plain HTML/CSS/JavaScript whac-a-mole tutorial project.

No source code was copied from the reference repository. The Kanami.top version keeps the broad tap-the-target idea, uses local Kanami assets, and implements its own HTML, CSS, and JavaScript.
