# Kanami Sweeper Credits

This game is hand-written for Kanami.top.

Original reference and thanks:

- [phartenfeller/minesweeper_js](https://github.com/phartenfeller/minesweeper_js) by phartenfeller, a plain JavaScript/CSS/HTML Minesweeper project under the MIT License.

No source code was copied from the reference repository. The Kanami.top version keeps the broad minesweeper rules, rethemes the board for Kanami.top, and implements its own HTML, CSS, and JavaScript.
