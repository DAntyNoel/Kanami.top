# Kanami Memory Credits

This game is hand-written for Kanami.top.

Original reference and thanks:

- [kubowania/memory-game](https://github.com/kubowania/memory-game) by Ania Kubow, a simple vanilla JavaScript memory-card game under the MIT License.

No source code was copied from the reference repository. The Kanami.top version keeps the same broad memory-card idea, uses local Kanami assets, and implements its own HTML, CSS, and JavaScript.
