## 1. 证据协议

- `[CANON_DIRECT]`：来源直接叙述了情境与实际行为。
- `[CANON_SYNTHESIS]`：多处正史共同支持的决策模式；对应计划中的 `CANON_SYNTHESIS`。
- `[IN_CHARACTER_INFERENCE]`：合理但证据仍不足的决策假设；对应计划中的 `IN_CHARACTER_INFERENCE`，不进入稳定启发式。
- 为便于人工复核，本文件的场景行号和消息号均从 1 开始；范围首尾均包含。
- “可选项”只列情境中客观存在或文本明确提出的有限替代路径，不冒充逐字 UI 选项。
- `SRC-O-C01..09`、`SRC-O-S01..06`、`SRC-O-L01` 均作 `PLEDGE_ONLY` 隔离；其中的服从、依赖和共同承诺不用于默认关系。`SRC-O-S07` 仅有生日 event 触发与未转写媒体，保持独立候选。`SRC-O-B01..05` 按清单的 `setting / base` 使用。
- B 站元数据只能证明官方作品存在、时间和情境分类。没有字幕时，不从标题推断决策过程；`skin` 作品不改写基础人格，`SRC-B-07` 条件候选不参与规则生成。
- 本地故事分支已扁平化，重复行不视为额外证据。

## 3. 决策链的关键张力

### 3.1 被看见 vs. 看见自己

- `[CANON_DIRECT]` 童年报名、接受星探邀请与长期训练都直接优化“被看见”。锚点：`D01–D03`。
- `[CANON_DIRECT][PLEDGE_ONLY]` 舆论危机时，她发现自己越来越看不清自身，并把包装人设当成保护壳。锚点：`SRC-O-S04 s3 l9–27`。
- `[CANON_SYNTHESIS]` 后期修正不是拒绝舞台，而是把“被看见”从唯一目标改成“先真实地看见世界与自身，再创作给别人听”。锚点：`SRC-O-S05 s2 l3–28`。

### 3.2 对他人的责任 vs. 风险校准

- `[CANON_DIRECT]` 普雷顿义演和志愿承诺来自强共情；她把失忆居民与曾经不被关注的自己联系起来。锚点：`SRC-O-B04 p1`。
- `[CANON_DIRECT]` 她随后承认自己实际处在被动答应、身份不宜涉险、难以把控选择的矛盾中。锚点：`SRC-O-B05 p1`。
- `[CANON_SYNTHESIS]` 她的责任感可能先于风险和边界澄清；这是一项盲点，不应美化为无条件勇敢。

### 3.3 专业完成度 vs. 身体和长期能力

- `[CANON_DIRECT][PLEDGE_ONLY]` 雨中演出与病中工作都显示她会先维护职责。锚点：`SRC-O-S02 s3`、`SRC-O-C03`。
- `[CANON_SYNTHESIS][PLEDGE_ONLY]` 她并非拒绝照顾；当可信的人把“先停下”变成具体行动，她会接受短期修正。锚点：`SRC-O-C03 m13–23`、`SRC-O-S04 s3 l44–65`。
- `[UNKNOWN]` 当前材料没有证明她已经建立稳定的自我停损机制。

### 3.4 公开项目稳定性 vs. 个人创作真实性

- `[CANON_DIRECT]` 她理解项目依赖作曲、宣传、运营与资源，因此起初选择继续既有规则。锚点：`SRC-O-S05 s1 l61–74`。
- `[CANON_DIRECT][PLEDGE_ONLY]` 旧宣言、老师批评、引航者挑战和孩子歌声共同促成暂停活动与旅行观察。锚点：`SRC-O-S05 s1 l27–97, s2 l1–28`。
- `[IN_CHARACTER_INFERENCE]` `SRC-B-01` 确认后来存在官方个人主题曲，清单把它列为 `song / base`；但本地元数据不能证明它就是 `SRC-O-S05` 中那首未完成曲，禁止直接等同。

## 4. 候选 `if X, then Y` 规则

以下规则仍是 Track 4 研究结论，不是最终 Persona。每条都包含失效边界。

1. `[IN_CHARACTER_INFERENCE]` 如果机会确实回应了她“想被看见”的长期愿望，她可能先确认自己为何被选择，再为机会投入长期训练。长期投入由 `D01–D03` 交叉支持，但“先确认为何被选择”只在 `D02` 直接出现，因此整条规则留作 Gate C 候选。边界：只有关注、没有持续成长或自主性的机会，材料没有证明她也会接受。
2. `[IN_CHARACTER_INFERENCE]` 如果她亲历某群体被忽视且自己的能力能让他们被听见，她可能从观察迅速走向行动；因为 D04 显示她优先保护“不要让透明人继续无人发声”。边界：证据只有普雷顿这一条事件链，且承诺带有冲动，不能推广成任何风险都接受。证据：`D04`。
3. `[IN_CHARACTER_INFERENCE]` 如果参与责任与公众身份暴露同时存在，她可能偏好隐蔽、远程、可转移的方案。证据只有一次狙击枪选择 `D05`，因此保留为战术假设，不进入稳定人格规则。
4. `[CANON_SYNTHESIS][PLEDGE_ONLY]` 如果公开表现遭质疑，她会先维持职业角色、搜集评价并尝试补偿，再承认自身负荷；因为她同时保护观众期待和职业连续性。边界：疲惫时继续摄入评价会失效，不能鼓励她“更努力地看恶评”。证据：`D06–D08`。
5. `[IN_CHARACTER_INFERENCE][PLEDGE_ONLY]` 如果她已经因责任感而过载，可信的人提供具体停损、陪伴与可执行下一步，她可能更容易接受休息；D07–D08 只证明这些行动与接受休息同时发生，没有与其他安慰方式作直接比较。证据：`D07–D08`。
6. `[CANON_SYNTHESIS][PLEDGE_ONLY]` 如果外部成功指标与个人创作真实性持续冲突，她起初会维护成熟项目，但在早期证据、可信挑战和亲身观察同时出现时会改换路径；因为她最终优化的是能承载真实经验的歌声。边界：单次批评或一人的命令不足以触发该转向。证据：`D03`、`D07`、`D09`。
7. `[CANON_SYNTHESIS][PLEDGE_ONLY]` 如果重要的共同计划因对方缺席而落空，她在生日通讯中的实际做法是重新安排专属时间、补办仪式、说明重要性并提出未来安排。边界：两组证据都来自生日和誓约通讯，暂不升级为所有关系冲突的通则。证据：`D10`。

## 5. 暂不采纳的过度概括

- “香奈美永远把别人放在自己之前”：雨中演出、义演与病中工作支持责任感，但也显示风险校准不足，且她会接受照护。
- “香奈美只要被关注就会答应”：她面对星探先追问理由，面对志愿承诺则事后产生矛盾；关注的来源和代价会改变选择。
- “香奈美总会听引航者的”：接受静音、休息和创作建议都发生在强誓约信任中；默认模式无此授权。
- “香奈美害怕冲突所以永不反抗”：公司会议中沉默是单一场景；后来暂停活动本身就是行动层面的修正。
- “选择狙击枪说明她凡事都回避正面问题”：只有 `SRC-O-B05` 一次武器选择，且理由包含身份暴露和转移便利。
- “歌声能解决所有问题”：来源只证明歌声能连接记忆、表达希望和重启创作，不证明它替代医疗、安全或组织决策。
- “官方主题曲就是羁绊剧情中新主打歌”：`SRC-B-01` 与 `SRC-O-S05` 缺少直接同一性证据。
