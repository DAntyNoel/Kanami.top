# 05｜旁白与他者视角

> 阶段：Gate B 研究完成，待用户确认
> 基线：中文 PC 正史；2026-08-14 本地快照与网页核验
> 原则：把官方简介、官方观测、小传旁白、剧情旁白和角色评价分开；不以玩家评论或相关推荐代替正史

## 1. 证据协议

- `CANON_DIRECT`：来源直接给出的旁白、评价或可见页面信息。
- `CANON_SYNTHESIS`：多个外部视角共同支持的稳定印象或张力。
- `IN_CHARACTER_INFERENCE`：可能的盲点，只作为 Gate C 候选。
- `UNKNOWN`：评价者、版本、说话人或网页内容不能确认。
- 网页证据锚到 `knowledge/inventory/web-verification.json`；本地长文本只给 source_id 与 JSON 位置，不复制长段落。

## 4. 有证据的张力

### E1｜完美偶像 vs. 可被照顾的人

- `CANON_DIRECT`：`SRC-M-01` 主页以闪耀、高人气和完美声线描述公开定位。
- `CANON_DIRECT`：`SRC-O-S03–S04` 旁白观察到会议后的疲惫、信息过载和不熟悉被真诚照顾的反应。
- `CANON_SYNTHESIS`：她不是“外强中干”，而是公开能力与私人照护经验不对称。

### E2｜公众期待 vs. 自主判断

- `CANON_DIRECT`：`SRC-O-B03`、`SRC-O-S03` 显示行业定位、热度和评价强烈影响她的工作选择。
- `CANON_DIRECT`：`SRC-O-S05` 的老师和旧乐谱提醒她早期创作目标。
- `CANON_SYNTHESIS`：她需要把回应观众与形成自身经验重新连接，而非在“讨好别人／完全无视别人”之间二选一。

### E3｜被看见 vs. 看见被遗忘者

- `CANON_DIRECT`：`SRC-O-B01–B02` 说明她早期强烈希望获得关注。
- `CANON_DIRECT`：`SRC-O-B04–B05` 说明普雷顿经历把这种个人经验转为对被遗忘者的共情。
- `CANON_SYNTHESIS`：她的舞台不只是自我展示，也可能成为让别人被听见的工具；但该转化伴随冲动承诺风险。

### E4｜舞台中心 vs. 隐蔽行动

- `CANON_DIRECT`：官方主页把她定位为偶像歌手与地下志愿者；`SRC-O-B05` 描述她因身份暴露风险选择狙击武器。
- `CANON_SYNTHESIS`：可见性和隐蔽性同时存在，是身份结构的张力；不能把狙击枪一次选择升级为“凡事逃避正面冲突”。

## 5. 候选盲点

1. `IN_CHARACTER_INFERENCE`：她可能高估“继续表现得很好”对关系和团队的保护作用，低估及时暴露负荷的价值。证据：`SRC-O-B03`、`SRC-O-S03–S04`。
2. `IN_CHARACTER_INFERENCE`：她可能把强烈共情过快转换为个人承诺，之后才补做风险判断。证据：`SRC-O-B04–B05`。
3. `IN_CHARACTER_INFERENCE`：她可能把可量化的评价当作较容易抓住的自我尺度，即使这些评价会伤害判断。证据：`SRC-O-S03–S04`。
4. `IN_CHARACTER_INFERENCE`：真正被照顾时的生疏，可能使她更晚求助；当前样本高度集中在誓约剧情，不能泛化。

这些项目必须在 Gate C 以反例和失效条件审查；不能写成心理诊断。

## 6. 不可使用的外部声音

- B 站评论、相关推荐、COS 投稿标题和播放数据不构成正史人格证据。
- `SRC-B-07` 页面出现“香奈美”仅因相关推荐中的 COS 投稿；官方视频本体仍未证明包含有效片段。
- 玩家二创、KanamiBot 表情包文字和群聊元数据不能证明角色台词或行为。
- 官方宣传标题只证明作品定位；未观看、无字幕时不能替角色本人发言。
- WIKI 编辑者、更新者姓名只证明页面维护，不是版权方的角色评价。

## 7. 他者视角薄弱点

1. 明、经纪人、卡蒂、夏露、老师和粉丝的独立长篇观点不足；多数经旁白转述。
2. 基础主线中的队友评价明显少于誓约剧情中的引航者观察，关系样本失衡。
3. B 站 6 个核心视频只完成页面身份核验，未提取旁白、字幕、镜头关系和时间戳。
4. 主页观测语录只有一段，不能单独定义全部私下人格。
5. `SRC-O-S06/S07` 音频标记没有回听，缺少歌曲完成和生日事件中的外部反应。
6. 移动端、多语言和后续版本是否新增他者评价尚未核对。

## 8. Gate B 可保留结论

- `CANON_SYNTHESIS`：公众看到的完美偶像是真实能力，但不是她的全部状态。
- `CANON_SYNTHESIS`：公开优等生与私下轻度逗弄由官方观测和互动材料交叉支持。
- `CANON_SYNTHESIS`：她最稳定的外部张力是“被评价定义”与“重新形成自身判断”。
- `CANON_SYNTHESIS`：对被遗忘者的共情有外部事件与官方简介支持，不只是自我美化。
- `UNKNOWN`：除引航者外的关系网络仍偏薄，Gate C 不能据此生成过于完整的社交模型。
