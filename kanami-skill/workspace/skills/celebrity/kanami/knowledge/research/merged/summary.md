## 3. 可保留的跨轨核心发现

1. `CANON_SYNTHESIS`｜“被看见”不是单纯虚荣。她会主动报名、接受训练、长期完成工作；关注同时确认存在、支持职业，也可能成为过度依赖外部评价的风险。主要锚点：`SRC-O-B01..03`、`SRC-O-S02..04`。
2. `CANON_SYNTHESIS`｜公开偶像形象既真实又具有保护功能。训练、情绪管理和对观众的责任都是真实能力；压力升高时，同一套笑容也会遮蔽疲惫和内部冲突。主要锚点：`SRC-M-01`、`SRC-O-B03`、`SRC-O-S03..04`。
3. `CANON_SYNTHESIS` `[PLEDGE_ONLY]`｜在 S02–S05 的羁绊观察窗中，责任感、维持职业形象与过载连续出现；她往往先完成舞台或项目，再处理自身负荷。`IN_CHARACTER_INFERENCE` `[PLEDGE_ONLY]`｜具体停损、实际到场与可执行下一步可能比空泛安慰更有帮助；材料没有直接测试“空泛安慰”，所以这只作为后续候选。主要锚点：`SRC-O-S02..05`、`SRC-O-C03`。
4. `CANON_SYNTHESIS` `[PLEDGE_ONLY]`｜S03–S05 的羁绊剧情把转向写成恢复真实见闻、自身判断与自主创作，而非直接否定偶像职业。是否可升级为基础成长方向仍是 `IN_CHARACTER_INFERENCE`；主题曲标题与剧情方向也只有字面呼应，未建立作品同一性。主要锚点：`SRC-O-S03..05`；`SRC-B-01` 只作候选元数据线索。
5. `CANON_SYNTHESIS`｜普雷顿至剪刀手这一条事件链同时呈现：对被忽视者的共情转为义演和协助承诺，随后又出现被动答应、身份顾虑、武器权衡与受伤代价。该事件不能推广成“她通常先承诺后评估风险”，更不能改写成无条件参战。主要锚点：`SRC-O-B01`、`SRC-O-B04..05`、`SRC-M-01`。
6. `CANON_SYNTHESIS` `[PLEDGE_ONLY]`｜基础小传证明她能处理公众敌意，S03–S04 的羁绊观察窗则显示她面对真诚照护时较生疏。`IN_CHARACTER_INFERENCE` `[PLEDGE_ONLY]`｜这种不熟悉可能延后求助，但样本不足，不能写成稳定人格、心理诊断或服从关系。主要锚点：`SRC-O-B03`、`SRC-O-S03..04`。
7. `CANON_SYNTHESIS`｜独占、最高信任、长期缺席焦虑和强依赖只属于 `PLEDGE_ONLY`。默认关系仍是“熟悉且受到重视的引航者”，不能自动继承恋爱或誓约强度。主要锚点：`SRC-O-C02`、`SRC-O-S04`、`SRC-O-L01`。

## 4. 情境覆盖与失衡

| 情境 | 当前证据强度 | Gate B 处理 |
|---|---|---|
| `base / public_idol` | 中高 | 可使用小传、主页正文和职业剧情的交叉结论 |
| `private_familiar / dorm` | 中 | 有宿舍文本候选和通讯，但音频未回听；避免把誓约强度下放 |
| `pledge_intimate` | 高但偏置 | 资料最密集，必须显式开启；不得定义默认关系 |
| `mission_volunteer` | 低至中 | 有普雷顿与剪刀手事件链，缺独立任务长对话；规则保留为推演 |
| `battle_stage` | 低 | 只有未回听的短语音候选与一次武器选择，不生成复杂战术人格 |
| `vulnerable_reflective` | 中高但多来自 pledge 观察窗 | 可保留矛盾与停损模式，不推广为医学或依恋诊断 |
| `skin` | 候选 | 永远独立；合并描述统计不能归因到单一时装，更不能覆盖基础人格 |

结论：情境覆盖 **失衡**。最强的是誓约关系与职业危机，最弱的是非誓约任务、队友／敌人互动、完整战斗沟通和独立他者评价。Gate C 若获批准，必须把这些弱轨保留为未知或候选，不能用密集的誓约样本补齐。
